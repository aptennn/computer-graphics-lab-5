# Лабораторная работа 5 — фракталы и кривые Безье

Проект собирается через CMake с Qt Widgets (Qt 5 или 6). В приложении четыре вкладки.

## 1а. L-системы и 1б. Фрактальное дерево — Михаил

Вкладки пока оставлены пустыми. Реализация этих частей будет добавлена отдельным
коммитом Михаила.

## 2. Midpoint displacement — Лилия

На каждом шаге высота середины отрезка вычисляется по формуле со слайда 59
лекции 6:

```text
h = (hL + hR) / 2 + random(-R * L, R * L)
```

Где `L` — длина разбиваемого отрезка, а `R` — шероховатость. Ползунок «Поколение»
показывает исходный отрезок и все последовательные шаги до итоговой ломаной.

## 3. Составная кубическая кривая Безье — Егор

Левый клик добавляет или захватывает опорную точку, перетаскивание перемещает её,
правый клик удаляет. Управляющие точки кубических сегментов вычисляются
автоматически из соседних опорных точек и не редактируются пользователем.
