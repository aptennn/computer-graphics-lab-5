# Лабораторная работа 5 — фракталы и кривые Безье

Проект собирается через CMake с Qt Widgets (Qt 5 или 6). В приложении четыре вкладки.

## 1а. L-системы и 1б. Фрактальное дерево — Михаил

На вкладке **1а** доступны семь примеров: кривая Коха, квадратный остров Коха,
кривые Гильберта и дракона и три куста. Число итераций меняется от 0 до 8.
Рисунок автоматически вписывается в окно с сохранением пропорций.

Кнопка **«Открыть файл с правилами…»** загружает `.lsys` или `.txt`. Первая
значимая строка содержит аксиому, угол поворота и начальное направление в градусах.
Направление `0` означает вправо, `90` — вверх. Далее идут правила подстановки:

```text
X 22.5 90
F -> FF
X -> F-[[X]+X]+F[+FX]-X
```

Пустые строки и строки, начинающиеся с `#`, пропускаются. Вместо `->` можно
использовать `→`. `F` рисует отрезок, `+` и `-` поворачивают черепашку,
`[` сохраняет её состояние, `]` восстанавливает. Остальные символы участвуют
в подстановках без рисования. Несколько правил для одного символа выбираются
случайно с равной вероятностью. Готовые файлы находятся в `examples/`.
При ошибке загрузки предыдущий рисунок сохраняется. Чтобы ограничить рост
L-системы, длина поколения ограничена 2 000 000 символов.

На вкладке **1б** показано фрактальное дерево на основе третьего куста.
Толщина ветвей уменьшается от ствола к концам, цвет меняется от коричневого
к зелёному. Параметры **«Разброс угла»** и **Seed** управляют случайными
отклонениями: одинаковый seed при одинаковых параметрах даёт тот же рисунок.
Кнопка **«Новый случайный рисунок»** меняет seed.

## 2. Midpoint displacement — Лилия

На каждом шаге высота середины отрезка вычисляется по формуле со слайда 59
лекции 6:

```text
h = (hL + hR) / 2 + random(-R * L, R * L)
```

Где `L` — длина разбиваемого отрезка, а `R` — шероховатость. Ползунок «Поколение»
показывает исходный отрезок и все последовательные шаги до итоговой ломаной.

## 3. Составная кубическая кривая Безье — Егор

Левый клик добавляет или захватывает опорную точку, перетаскивание перемещает её,
правый клик удаляет. Управляющие точки кубических сегментов вычисляются
автоматически из соседних опорных точек и не редактируются пользователем.
